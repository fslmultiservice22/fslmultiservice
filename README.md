# FSL Multiservice — Sito aziendale

Questo repository contiene il sito informativo di **FSL Multiservice S.r.l.s.**. Il sito è separato dal progetto tecnologico AgentPay e descrive esclusivamente le attività aziendali indicate nella documentazione fiscale: servizi di supporto alle imprese e logistica accessoria in Italia.

## Pubblicazione

La pubblicazione deve avvenire solo dopo verifica dei contenuti e conferma esplicita del titolare. Per GitHub Pages, configurare la pubblicazione dalla radice del branch `main` e associare il dominio solo dopo aver verificato l'attuale configurazione DNS.
